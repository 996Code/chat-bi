threat_model:
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → /datasources | Untrusted connection credentials (host/port/password) — validated before use |
| Server → MySQL database | Outbound connection to user-specified host — must use read-only mode |
| Database → credential storage | Passwords encrypted with Fernet; key from env, never stored in DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-11 | Information Disclosure | credential storage | mitigate | AES-256 (Fernet) encryption; key from DATA_SOURCE_ENCRYPTION_KEY env var; encrypted fields named *_encrypted to prevent accidental plaintext write |
| T-01-12 | Tampering | MySQL connection | mitigate | Connection uses `read_only=True` MySQL parameter; only SELECT allowed at DB level (SEC-02) |
| T-01-13 | Denial of Service | connection pool | mitigate | Pool size capped (5 + 10 overflow); 30s timeout on connection acquisition; leak prevention with async context manager |
| T-01-14 | Spoofing | datasource CRUD | mitigate | All routes require JWT auth; tenant_id filtered in query (TENANT-02); user cannot access another tenant's datasources |
</threat_model>

       ```python
       from cryptography.fernet import Fernet
       from app.core.config import settings

       def _get_fernet() -> Fernet:
           key = settings.data_source_encryption_key.encode()
           # Fernet requires 32 url-safe base64-encoded bytes
           # If user provides raw 32-byte key, encode it
           import base64
           if len(key) == 32:
               key = base64.urlsafe_b64encode(key)
           return Fernet(key)

       def encrypt_value(plaintext: str) -> str:
           return _get_fernet().encrypt(plaintext.encode()).decode()

       def decrypt_value(ciphertext: str) -> str:
           return _get_fernet().decrypt(ciphertext.encode()).decode()
       ```

    1. Create `backend/app/services/mysql_schema_scanner.py`:
       - `async def scan_mysql_schema(engine, db: AsyncSession, ds_id: str) -> dict`:
         a. Execute `SELECT TABLE_NAME, TABLE_COMMENT FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_SCHEMA = :db AND TABLE_TYPE = 'BASE TABLE'`
         b. For each table, execute `SELECT COLUMN_NAME, COLUMN_TYPE, IS_NULLABLE, COLUMN_KEY, COLUMN_COMMENT, DATA_TYPE FROM INFORMATION_SCHEMA.COLUMNS WHERE TABLE_SCHEMA = :db AND TABLE_NAME = :table ORDER BY ORDINAL_POSITION`
         c. Execute `SELECT TABLE_NAME, COLUMN_NAME, REFERENCED_TABLE_NAME, REFERENCED_COLUMN_NAME FROM INFORMATION_SCHEMA.KEY_COLUMN_USAGE WHERE TABLE_SCHEMA = :db AND REFERENCED_TABLE_NAME IS NOT NULL`
         d. Build metadata dict matching META-01 JSON Schema format:
            ```json
            {
              "version": "1.0",
              "database": {"type": "mysql", "name": "production_db"},
              "models": [
                {
                  "name": "t_order",
                  "table": "t_order",
                  "description": "订单表",
                  "columns": [
                    {"name": "id", "column": "id", "type": "bigint", "nullable": false, "primary": true}
                  ],
                  "relationships": []
                }
              ]
            }
            ```
         e. Save to metadata_configs table (create new version)
         f. Update data_source: table_count, last_schema_sync, metadata_sync_status="synced"
         g. Return `{"tables": [...], "total_tables": N}`

    2. Create `backend/app/services/connection_pool.py`:
       - Class `ConnectionPoolManager`:
         - `_pools: dict[str, AsyncEngine]` — singleton, one pool per datasource_id
         - `async def get_pool(ds: DataSource) -> AsyncEngine`:
           a. If ds.id in _pools, return existing
           b. Decrypt credentials, build URL: `mysql+aiomysql://{user}:{pass}@{host}:{port}/{db}?charset=utf8mb4&read_only=on`
           c. Create engine with pool settings: pool_size=5, max_overflow=10, pool_timeout=30, pool_recycle=3600, pool_pre_ping=True
           d. Store in _pools, return
         - `async def close_pool(ds_id: str) -> None`: dispose engine, remove from _pools
         - `async def close_all() -> None`: dispose all engines (shutdown hook)
         - `async def health_check(ds_id: str) -> dict`:
           a. Get pool, execute `SELECT 1`
           b. Update last_health_check in DB
           c. If fails: set status="error", health_check_error=str(error)
           d. Return `{"healthy": bool, "error": str | None}`
         - Register shutdown: `@app.on_event("shutdown")` calls `close_all()`
