## 关键修复

### 1. `conversation.py` SQL 查询写法错误

修改 `list_conversations` 时直接 `await q.order_by()` 导致 `Internal Server Error`，需要用 `await db.execute(q.order_by())` 包裹。

### 2. 前端 SSE 流绕过 baseURL

`chatStore.ts` 的 `streamQuery` 用原生 `fetch` 直接拼接 URL，没有走 axios 实例。修改时漏了该处，导致流式请求仍用旧前缀。后续补上。

### 3. Dockerfile 命名

最初命名为 `Dockerfile.allinone`，`docker compose` 默认找不到，改为 `Dockerfile`。

### 4. config.py 默认值仍是 SQLite

历史遗留，默认值从 `sqlite+aiosqlite:///./chatbi.db` 改为 `mysql+aiomysql://...`，注释也更新了。
