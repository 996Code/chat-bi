# ChatBI v2 操作指南

## 快速开始（本地开发）

### 1. 前置条件
- Docker Desktop（运行 PG + Milvus）
- Python 3.12+（`uv` 管理）
- Node.js 18+（前端）
- 讯飞 MAAS API Key（LLM）

### 2. 启动基础设施

```bash
# 启动 PG + Milvus (首次拉镜像较慢)
docker compose -f docker/docker-compose.infra.yml up -d

# 等待 healthy (Milvus ~90s)
docker compose -f docker/docker-compose.infra.yml ps
```

### 3. 配置环境变量

```bash
# 编辑 backend/.env (已配好本地默认值, 只需填 LLM API Key)
# 关键配置:
#   DATABASE_URL=postgresql+asyncpg://root:root@localhost:5432/chatbi
#   MILVUS_URL=http://localhost:19530
#   LLM_URL=你的 LLM endpoint
#   LLM_API_KEY=你的 key
```

### 4. 下载 Embedding 模型（首次，~1.3GB）

```bash
uv run python backend/scripts/download_embedding_model.py
```

### 5. 初始化数据库

```bash
# 建元数据表
uv run python -c "
import asyncio
from sqlalchemy.ext.asyncio import create_async_engine
from app.core.config import get_settings
from app.db.models import Base
async def main():
    engine = create_async_engine(get_settings().database_url)
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)
    await engine.dispose()
asyncio.run(main())
"

# 建示例业务库 + 数据
docker exec -i chatbi-infra-postgres psql -U root -d postgres -c "CREATE DATABASE chatbi_sample;"
docker exec -i chatbi-infra-postgres psql -U root -d chatbi_sample < backend/scripts/seed_business_schema.sql
SEED_DB_HOST=localhost SEED_DB_NAME=chatbi_sample uv run python backend/scripts/seed_business_data.py

# Seed 租户 + 用户 + 数据源 (见 backend/scripts/seed_meta.py)
```

### 6. 启动服务

```bash
# 后端 (推荐用启动脚本, 隔离 shell 环境变量)
./start-backend.sh

# 前端
cd frontend && npx vite --host 0.0.0.0 --port 5173
```

### 7. 访问

- 前端: http://localhost:5173
- 后端 API: http://localhost:8999/chat-bi/api/v1
- API 文档: http://localhost:8999/docs
- 健康检查: http://localhost:8999/health

## 常用操作

| 操作 | 命令 |
|------|------|
| 跑测试 | `uv run pytest backend/tests/ -q` |
| 跑测试+覆盖率 | `uv run pytest --cov=backend/app --cov-fail-under=75` |
| 跑慢测试(真实模型) | `uv run pytest -m slow` |
| 清 Milvus 数据 | 删 `docker/data/milvus/` + 重启 |
| 清对话状态 | 删 `data/states/` |
| 看 Skills 规则 | `skills/*/SKILL.md` |
| 改业务规则 | 编辑 SKILL.md → 下次查询自动生效 (热更新) |

## 架构概览

```
用户 → 前端 (Vue3) → 后端 (FastAPI :8999)
                        ├── 意图识别 → 检索 (Milvus+BGE) → SQL生成 → 三层校验
                        ├── 执行 (业务库 PG) → 自愈 → 结果自检 → 图表生成
                        ├── Skills (业务规则注入) + 反馈系统
                        └── 对话管理 (StateStore + 压缩 + Recall)
                            
基础设施: PG (元数据+业务) + Milvus (向量) + 本地 BGE (embedding)
```
