## 关键修复

### 1. Refresh token 丢失 role
- auth.py refresh 端点 token_data 未包含 role → 添加 `"role": payload.get("role", "user")`

### 2. Datasource toggle 权限绕过
- 手动调用 `require_role("admin")(user)` 非 FastAPI 依赖 → 改为 `Depends(require_role("admin"))`

### 3. CSV 导出 500 错误
- query.py 引用不存在的 `csv_export` 服务 → 重写为内联 CSV 生成

### 4. Redis pipeline 未 await
- rate_limiter.py `pipe.execute()` 缺少 await → 改为 `await pipe.execute()`

### 5. Alembic 迁移 MySQL 不兼容
- `sa.String()` 无长度限制 → 改为 `sa.String(5000)` / `sa.Text()`

### 6. 对话时间戳显示"8小时之前"
- 后端返回 naive datetime 无时区信息 → ISO 8601 格式 + Z 后缀

### 7. 对话消息双重编码
- chatStore 每次更新都追加而非替换 → 修复序列化逻辑

### 8. 多轮对话上下文丢失
- SQL 生成未传入历史消息 → generation.py 接收 history 参数

### 9. Model/Migration 类型不同步
- 模型用 String，迁移用 Text → 统一为 Text（长文本列），nullable 对齐

## 踩坑记录

| 问题 | 解决方案 |
|------|---------|
| FastAPI Depends 不能手动调用 | 权限检查必须通过函数签名 `Depends()` |
| Refresh token 缺字段 | payload 必须包含所有鉴权字段 |
| MySQL VARCHAR 必须指定长度 | `sa.String()` → `sa.String(N)` 或 `sa.Text()` |
| Model/Migration 类型不一致 | 定期对比，长文本统一用 Text |
| SSE 解析遍历中修改数组 | 改为索引遍历 `let i = 0; while (i < lines.length)` |
| 多轮对话 history 未传入 LLM | generation.py 增加 history 参数 |
