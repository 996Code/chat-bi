threat_model:
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → /query | Untrusted natural language input — validated for length, rate-limited |
| LLM → generated SQL | LLM output is untrusted — must pass AST validation before execution |
| SQL → MySQL database | Only SELECT allowed; read-only connection (defense in depth) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-15 | Prompt Injection | LLM prompt | mitigate | System prompt explicitly forbids non-SELECT; database connection is read-only (SEC-02) — double defense |
| T-01-16 | Tampering | generated SQL | mitigate | SQLGlot AST validation: reject any non-SELECT statement before execution |
| T-01-17 | Denial of Service | query execution | mitigate | 30s asyncio timeout (SQL-07); LIMIT 1000 enforced after execution (SQL-08); pool max_overflow=10 |
| T-01-18 | Information Disclosure | query results | mitigate | Results scoped to user's datasource; tenant_id filtering enforced at DB level via datasource ownership |
</threat_model>

       - `async def classify_intent(state: QueryState) -> dict`:

            ```
            你是一个意图分类器。根据用户的问题，判断其意图类型。

            类型定义：

    5. Create `backend/app/ai/graph.py` — LangGraph StateGraph:
       - `class QueryState(TypedDict)`:
         ```python
         class QueryState(TypedDict):
             user_query: str          # Original Chinese question
             tenant_id: str           # For filtering
             datasource_id: str       # Target database
             intent: str              # "DataQuery" | "Other"
             schema_context: str      # Table/column metadata as text
             generated_sql: str       # SQL generated by LLM
             result_data: list[dict]  # Query result rows
             columns: list[str]       # Column names
             row_count: int           # Number of rows
             response_text: str       # Text response (for Other intent, errors)
             error: str | None        # Error message if any
         ```
       - Build graph:
         ```
         graph = StateGraph(QueryState)
         graph.add_node("intent", classify_intent)
         graph.add_node("generate_sql", generate_sql)
         graph.add_node("execute", execute_sql)
         graph.set_entry_point("intent")

         def route_after_intent(state):
             if state["intent"] == "Other":
                 return END
             return "generate_sql"

         graph.add_conditional_edges("intent", route_after_intent, {"generate_sql": "generate_sql", END: END})
         graph.add_edge("generate_sql", "execute")
         graph.add_edge("execute", END)

         app = graph.compile()
         ```
       - Export `query_app = build_query_graph()`

       - Define `SYSTEM_PROMPT` template for SQL generation:
         ```
         你是一个 MySQL SQL 专家。请根据以下用户问题和数据库Schema生成SQL查询。

         规则：
         1. 只允许使用 SELECT 语句，禁止 INSERT/UPDATE/DELETE/DROP 等操作
         2. 使用标准 MySQL 8.0 语法
         3. 字符串比较时区分大小写
         4. 日期字段使用 created_at 而不是 updated_at
         5. 结果默认按时间倒序排列（除非用户要求其他排序）

         数据库Schema：
         {schema_context}

         用户问题：{user_query}

         请按以下步骤思考：
         1. 确定需要哪些表
         2. 确定过滤条件（WHERE）
         3. 确定聚合方式（GROUP BY / 聚合函数）
         4. 确定排序和限制（ORDER BY / LIMIT）
         5. 生成 SQL

         只返回SQL，不要解释。格式：
         ```sql
         SELECT ...
         ```
         ```

    3. Create `backend/app/ai/nodes/generation.py`:
       - `async def generate_sql(state: QueryState) -> dict`:
         a. Load schema_context from state (injected by calling code — will be empty for Phase 1 basic mode)
         b. If state has datasource_id, load metadata from metadata_configs table for that datasource
         c. Format schema_context as text: "表名 (字段: 类型, 注释)"
         d. Fill SYSTEM_PROMPT template with schema_context and user_query
         e. Call LLM (temperature=0.0 for deterministic SQL)
         f. Extract SQL from response (strip markdown code blocks)
         g. Basic validation: if SQL doesn start with SELECT (case-insensitive), prepend "SQL generation returned non-SELECT" warning
         h. Return state with `{"generated_sql": sql_text}`

    4. Create `backend/app/ai/nodes/execution.py`:
       - `async def execute_sql(state: QueryState) -> dict`:
         a. Validate SQL starts with SELECT (reject non-SELECT with error) — SQL-01 safety
         b. Use SQLGlot to parse: `sqlglot.parse(state["generated_sql"], read="mysql")`
            - If parse fails, return error: "SQL语法错误: {error}"
         c. Get datasource from DB, get engine from ConnectionPoolManager
         d. Execute SQL with asyncio timeout:
            ```python
            import asyncio
            try:
                async with asyncio.timeout(30):  # SQL-07: 30s timeout
                    async with engine.connect() as conn:
                        result = await conn.execute(text(generated_sql))
                        rows = result.fetchall()
                        columns = result.keys()
            except asyncio.TimeoutError:
                return state with error: "查询超时（超过30秒），建议缩小查询范围"
            ```
         e. Convert rows to list[dict]: `[{col: row[i] for i, col in enumerate(columns)} for row in rows]`
         f. Apply row limit (SQL-08): if len(data) > 1000, truncate to 1000, set truncated=True
         g. Return state with `{"result_data": data, "columns": columns, "row_count": len(data), "truncated": bool}`

    5. Create `backend/app/api/query.py`:
       - `POST /api/v1/query`:
         a. Validate request: query not empty, datasource_id valid, user owns datasource
         b. Get datasource, check status == "active"
         c. Load schema metadata for this datasource
         d. Build initial QueryState with user_query, tenant_id, datasource_id, schema_context
         e. Invoke LangGraph app: `result = await query_app.ainvoke(initial_state)`
         f. If intent == "Other", return `{"code": "QUERY_MISLEADING", "message": result["response_text"]}`
         g. If error in result, return 400 with error details
         h. Build QueryResponse: {query, sql, data, columns, row_count, truncated, elapsed_ms}
         i. Log to audit_logs (query_text, generated_sql, result_rows, status, duration_ms)
         j. Return 200 QueryResponse
  </action>
