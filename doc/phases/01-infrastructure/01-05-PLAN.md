threat_model:
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User browser → localStorage | JWT tokens stored in localStorage (v1); XSS risk — httpOnly cookies recommended for production |
| Frontend → Backend API | All requests include Authorization header; expired tokens trigger redirect to /login |
| Chat input → Backend | User input sent as-is; backend handles sanitization and intent classification |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-19 | Information Disclosure | localStorage tokens | accept | v1 uses localStorage for simplicity; production should migrate to httpOnly cookies (Phase 2) |
| T-01-20 | Tampering | API requests | mitigate | Axios interceptor adds Authorization header; 401 response triggers automatic token refresh or redirect to login |
| T-01-21 | Spoofing | CSRF | accept | SPA with JWT in headers (not cookies) — CSRF not applicable for token-based auth |
</threat_model>
