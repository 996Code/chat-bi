## 踩坑记录

- **LangGraph QueryState 字段必须声明**：节点返回的 key 如果不在 TypedDict 中，LangGraph 会静默丢弃。`schema_selection.py` 返回的 `raw_metadata`、`selected_tables` 等字段被丢弃导致后续节点拿不到数据。
- **pipeline_executor.py 直接调用节点函数**：不走 `graph.ainvoke()`，而是 step by step 调用每个节点函数并手动传递 state。重写为 `graph.ainvoke()` 时字段映射出错。
- **ResizeObserver contentRect vs clientHeight**：`overflow: auto` 容器中 `contentRect.height` 可能返回内容高度而非布局高度，改用 `clientHeight - padding` 更可靠。
- **flex:1 与 inline height 冲突**：`.echarts-wrapper` 同时设置 `flex: 1` 和 `height: Xpx`，flex-basis:0 会覆盖显式 height。去掉 `flex: 1`，让 inline height 生效。
