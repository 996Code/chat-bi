# Roadmap: ChatBI

**Created:** 2026-05-01
**Core Value:** 让不会 SQL 的人也能自助完成数据查询和可视化，3 秒内得到图表答案
**Total Phases:** 4
**Estimated Duration:** 8 weeks (2 weeks per phase)

---

## Phase 1: 基础设施（Week 1-2）

**Goal:** 能跑通"提问 → 返回结果"的最小链路

**Requirements Covered:** AUTH-01, AUTH-02, AUTH-03, AUTH-04, AUTH-05, AUTH-06, AUTH-07, AUTH-08, TENANT-02, DS-01, DS-05, DS-06, DS-07, META-01, SQL-01, SQL-02, SQL-07, SQL-08, CHART-02, SEC-02, UX-11, API-01, API-03, DSO-01, DSO-02, DSO-03, DSO-09

**Plans:** 5 plans in 4 waves

Plans:
- [ ] 01-01-PLAN.md -- 项目脚手架 + SQLite 数据库 + 6 个模型 + Alembic 迁移
- [ ] 01-02-PLAN.md -- 完整认证系统（注册/登录/JWT/密码重置/邮箱验证/登录锁定）
- [ ] 01-03-PLAN.md -- 数据源管理（MySQL CRUD/连接测试/表结构扫描/连接池/加密）
- [ ] 01-04-PLAN.md -- AI 查询管道（LangGraph 意图分类 -> SQL 生成 -> 执行/超时/行数限制）
- [ ] 01-05-PLAN.md -- 前端（Vue3 登录/注册/数据源管理/对话界面/数据表格/空状态）

**Deliverables:**
- 用户登录 -> 连接 MySQL -> 中文提问 -> 得到 SQL + 数据表格

**Success Criteria:**
- 能成功连接 MySQL 并执行查询
- 简单单表查询能生成 SQL（不要求高准确率）
- 前端能展示对话和表格结果
