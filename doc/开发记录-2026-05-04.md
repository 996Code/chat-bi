### 2. 本地缓存无法被清除
- 移除所有本地缓存，统一走 Redis

### 3. SQL 生成列名错误
- 补全 metadata 中文描述

### 4. 自愈后 SQL 未回写
- graph.py 中 self_heal 节点回写 fixed SQL

### 5. data_masking lambda bug
- lambda 参数从 match 对象改为字符串值

### 6. 登录锁不支持多实例
- 改为 Redis-backed，内存降级兜底

### 7. 分页非 cursor-based
- saved_query API 改为 cursor-based
