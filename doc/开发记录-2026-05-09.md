## 关键改进

### 1. 教学级中文注释

为 LangGraph 核心文件添加了详细的教学级中文注释，覆盖：
- **graph.py**：StateGraph 概念、QueryState TypedDict 字段说明、build_graph() 流程图、条件路由函数 route_by_intent()
- **pipeline_executor.py**：SSE 事件流（cache → intent → semantics → sql → data → chart → complete）、两级缓存策略（精确缓存 + 语义缓存）、自愈机制、async generator 模式

### 2. LLM API 认证错误处理

**问题**：LLM API Key 失效时，代码静默 fallback 返回空结果，用户只能看到"无法生成 SQL"，无法定位问题根因。

**解决方案**：
- 新增 `LLMAPIError` 异常类
- 新增 `is_auth_error()` 函数，检测 401 认证错误特征
- 在 `intent.py`、`generation.py`、`schema_selection.py` 中，检测到认证错误时立即抛出异常
- 其他错误（超时、网络）仍然静默降级，不影响可用性

**效果**：现在当 API Key 失效时，前端会收到明确的错误信息：
```
LLM API 认证失败，请检查 LLM_BASE_URL 和 LLM_API_KEY 配置。错误信息: ...
```
