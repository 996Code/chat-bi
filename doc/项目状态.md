## 本次修复的 Bug

| Bug | 根因 | 修复 |
|-----|------|------|
| Refresh token 丢失 role | auth.py refresh 端点 token_data 未包含 role | 添加 `"role": payload.get("role", "user")` |
| Datasource toggle 权限绕过 | 手动调用 `require_role("admin")(user)` 非 FastAPI 依赖 | 改为 `admin: dict = Depends(require_role("admin"))` |
| CSV 导出 500 错误 | query.py 引用不存在的 `csv_export` 服务 | 重写为内联 CSV 生成 |
| Redis pipeline 未 await | rate_limiter.py `pipe.execute()` 缺少 await | 改为 `await pipe.execute()` |
| Alembic 迁移 MySQL 不兼容 | `sa.String()` 无长度限制 | 改为 `sa.String(5000)` / `sa.Text()` |
| 对话时间戳显示"8小时之前" | 后端返回 naive datetime 无时区信息 | ISO 8601 格式 + Z 后缀 |
| 对话消息双重编码 | chatStore 每次更新都追加而非替换 | 修复序列化逻辑 |
| 多轮对话上下文丢失 | SQL 生成未传入历史消息 | generation.py 接收 history 参数 |
| Model/Migration 类型不同步 | 模型用 String，迁移用 Text | 统一为 Text（长文本列） |

## 关键技术决策

- AI Framework: LangGraph（确定性工作流）
- Semantic Layer: MDL-style + LLM 语义解析
- SQL Dialect: SQLGlot AST 校验
- Multi-tenancy: Shared table + tenant_id（全链路强制过滤）
- RBAC: require_role() 依赖工厂，admin/user/read_only 三角色
- Frontend: Vue3 + ECharts + Element Plus
- LLM: qwen3.6-plus（百炼 API），enable_thinking=false
- 缓存: Redis 统一（移除本地缓存）
